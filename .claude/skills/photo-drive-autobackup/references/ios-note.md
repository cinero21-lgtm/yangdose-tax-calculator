# 아이폰(iOS)인 경우

iOS는 백그라운드에서 임의의 스크립트를 돌릴 수 없다. 그래서 이 스킬의 안드로이드용
데몬을 그대로 옮길 방법이 없고, **단축어(Shortcuts) 자동화**로 근사치를 만든다.
한계를 먼저 솔직히 말해 주는 게 좋다.

## 무엇이 되고 무엇이 안 되나

| | 안드로이드(Termux) | iOS(단축어) |
|---|---|---|
| 촬영 즉시 자동 실행 | 된다 | **안 된다** — 앱 열기/시각/충전 시작 같은 트리거만 가능 |
| 업로드 해시 검증 | 된다 | 안 된다 (파일 크기 비교까지가 한계) |
| 자동 삭제 | 된다 | 된다. 단 iOS 16+는 "삭제 확인" 팝업을 대개 한 번 띄운다 |
| 30일 복구 | 자체 휴지통 | 사진 앱의 '최근 삭제됨'(30일)이 대신한다 |

즉 iOS에서는 **완전 무인 자동화가 아니라 반자동**이 현실적인 목표다.

## 권장 구성

1. 구글 드라이브 앱을 설치하고 로그인해 둔다.
2. 단축어 앱 → 새 단축어:
   - `사진 찾기` — 필터: *앨범이 최근 항목*, *생성일이 3일 이전*, 정렬: 생성일 오름차순,
     제한: 50개 (한 번에 너무 많이 처리하면 중간에 죽는다)
   - `파일 저장` — 서비스: 구글 드라이브, 경로: `PhoneCamera/`, '저장하기 전에 물어보기' 끄기
   - `사진 삭제` — 입력: 위에서 찾은 사진
3. 자동화 탭 → 개인용 자동화 → **충전기에 연결됨** (또는 매일 특정 시각) → 위 단축어 실행
   → '실행 전에 묻기' 끄기

'생성일 3일 이전' 조건이 안전장치다. 방금 찍은 사진은 아직 아이클라우드 동기화 중일 수
있으니 며칠 지난 것부터 넘긴다.

## 삭제 확인 팝업을 줄이려면

`사진 삭제` 동작은 iOS 버전에 따라 확인을 요구한다. 단축어 세부 설정에서 '실행 시 표시'를
끄면 줄어들지만, iOS 업데이트마다 동작이 달라져 왔다. 확실히 무인으로 돌리고 싶다면
사진 앱의 iCloud 사진 '기기 저장 공간 최적화'를 함께 쓰는 편이 낫다.

## 그래도 진짜 자동화가 필요하다면

- 안드로이드 폰을 세컨드로 두고 이 스킬을 쓰는 방법
- 맥/PC를 켜 두고, 아이폰이 Wi-Fi에 붙었을 때 사진을 당겨 오는 rclone 스케줄을 PC 쪽에
  거는 방법 (`rclone`은 iOS 기기를 직접 못 읽으므로 iCloud 사진 다운로드를 경유한다)

둘 다 부담스러우면, iOS에서는 '용량이 찰 때 반자동으로 비우기' 수준이 합리적인 기대치다.
